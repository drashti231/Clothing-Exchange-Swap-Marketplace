# Clothing Exchange & Swap Marketplace

A production-ready full-stack web application where users can exchange and swap clothing items.

## Features
- **User Authentication**: Register, Login, Role-based Access (Guest, User, Admin)
- **Marketplace**: Browse, Search, Filter (Category, Size, Brand, Condition, Location)
- **Swap System**: Propose swaps, calculate fair values, negotiate via real-time chat
- **Real-Time Chat**: Socket.io integration for instant communication during swap negotiation
- **Location Matching**: Find items nearby using geospatial queries
- **Admin Panel**: Dashboard for KPIs, User/Listing Management, Dispute Resolution

## Project Structure
- `/client`: React, Vite, Tailwind CSS frontend
- `/server`: Node.js, Express, MongoDB backend
- `/docs`: Project documentation
